## Portfolio Site

Highlights of this site: dark glass-style UI with gradient accents, animated stat counters, scroll-reveal sections, a tech-stack marquee, collapsible experience timeline, and a print-ready two-page resume layout (use the **Resume** button → Save as PDF).

All content lives in [`lib/resume-data.ts`](lib/resume-data.ts); print layout is in [`components/PrintResumeSection.tsx`](components/PrintResumeSection.tsx).

## Getting Started (Development)

This portfolio is a Next.js app. To run it locally:

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

Other scripts:

```bash
npm run build   # production build
npm run start   # run production server
npm run lint    # lint the project
```

Edit `lib/resume-data.ts` to update content, or `app/page.tsx` to change the page structure — it auto-updates on save.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to load Plus Jakarta Sans.
